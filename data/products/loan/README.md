# Loan product RAG sources

대출 상품설명서·상품비교표·대출 계약서류를 보관합니다. 현재 PDF 9개가 들어 있으며 ingest 시 모두 상품 대출로 분류됩니다.

## 포함 자료

- 가계대출 상품설명서
- 신용대출·담보대출·자동차대출·전월세·집단중도금·이주비 상품비교표
- 대출거래약정서(가계용)
- 고액 신용대출 사후 용도관리 추가약정서
- 내집마련 디딤돌 대출 상품설명서

공통 적용 약관인 은행여신거래기본약관(가계용)은 상품 문서와 구분하기 위해 data/regulations/loan에 보관합니다.

## 메타데이터 상태

- 2025 가계대출 상품설명서: 유효기간 2025-01-13 ~ 2026-06-30
- 2026 디딤돌 상품설명서: 유효기간 2026-01-01 ~ 2027-12-31
- 나머지 자료: 원문에 정확한 시행 시작·종료일이 없어 시점 미상
- 원본 URL·수집 시각·상품별 버전 ID는 다운로드 정보에 없어 별도 보강 필요

상품비교표는 요약 정보이므로 실제 민원 판단에는 계약서·약관·해당 시점의 금리표를 우선 사용해야 합니다.

## 가상 고객 연결

상품 문서는 RAG의 근거 자료이고, 고객의 실제 계약·거래 사실은 별도 가상 데이터입니다.

- 고객: `CUST-001`
- 대출 계좌: `LOAN-001`
- 상품: KB 직장인든든 신용대출
- 저장소: `server/finance/mock_bank.sqlite3`
- 조회 경로: `Finance MCP` 읽기 전용 Tool

이 데이터는 데모와 에이전트 흐름 검증을 위한 합성 데이터이며 실제 은행 고객정보가 아닙니다. 대출 상품 문서와 가상 계약 데이터는 RAG 검색과 사실 검증 단계에서 함께 사용합니다.
