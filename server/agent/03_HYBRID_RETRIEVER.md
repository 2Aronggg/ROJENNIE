# Hybrid Retriever Rules

## 목적

구조화된 민원 정보로 공통 규정, 상품 문서, 사례를 검색하고 근거 위치를 반환한다.

## 검색 순서

```text
공통 금융소비자 규정
→ 상품·쟁점별 약관과 상품설명서
→ 공식 분쟁조정·민원 사례
```

공통 규정과 상품 문서가 서로 다른 결론을 보이면 둘 다 반환하고 Logic Verification으로 넘긴다.

## 쿼리 구성

검색어는 다음 정보를 조합한다.

```text
issue_type + product + focal_type + disputed_fact + relevant_date
```

예: `적금 + 우대금리설명부족 + 상품설명서 + 우대금리 조건 + 가입일`

## 메타데이터 필터

- 상품
- 쟁점 유형
- 문서 유형
- 출처
- 시행일
- 페이지·섹션

## 근거 규칙

- 검색 결과마다 `doc_id`, 문서명, 페이지·섹션, 적용 시점을 반환한다.
- 자체 제작 민원 JSON·CSV는 법령 근거로 검색하지 않는다.
- 시행일이 사건일 이후인 규정은 현재 사건의 근거로 사용하지 않는다.
- 결과가 없으면 검색 실패가 아니라 `evidence_insufficient`로 표시한다.
