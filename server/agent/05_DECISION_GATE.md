# Decision Gate Rules

## 목적

각 민원의 다음 행동을 결정한다. 이 모듈은 별도 LLM 에이전트가 아니라 검증 결과를 해석하는 정책 단계다.

## 결정 규칙

```text
핵심 사실 부족 또는 대상 모호성       → ask
개인정보 마스킹·증빙 정리가 필요       → amend
사실과 근거가 충분하고 위험이 낮음     → proceed
사기·명의도용·법률 판단·중대한 충돌    → hold
```

## 우선순위

```text
hold > ask > amend > proceed
```

단, `hold`는 위험 신호가 실제로 존재할 때만 사용한다. 단순히 검색 결과가 적다는 이유로 모든 민원을 보류하지 않는다.

## 반드시 hold 또는 ask로 보내는 경우

- 명의도용·비인가 거래 의심
- 계약·거래·답변의 핵심 금액이 서로 다름
- 적용 규정의 시행일이 불명확함
- 제출 권한 또는 대리 권한이 확인되지 않음
- 사용자가 요구한 결론이 법률 판단을 필요로 함
