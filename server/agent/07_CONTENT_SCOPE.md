# Content Scope Rules

## 역할

사용자에게 보여줄 정보와 내부 처리용 정보를 분리한다. 내 금융정보·MCP·RAG의 모든 반환값을 그대로 화면에 출력하지 않는다.

## 기본 허용 정보

```text
allowed_fields
  민원 요약
  확인된 상품·계약 조건
  필요한 거래 사실
  시스템 계산 결과와 산식
  검증된 근거의 문서명·페이지·조항·짧은 인용문
  처리결과·소비자 유의사항·후속 절차
```

## 기본 제외 정보

```text
excluded_fields
  고객 내부 ID
  세션 토큰
  LLM 프롬프트
  MCP 내부 요청·응답 전문
  검색 방식
  similarity_score
  내부 chunk/vector ID
  검증되지 않은 RAG 후보를 확정 근거처럼 표시한 내용
```

## 마스킹 대상

- 주민등록번호
- 전체 계좌번호
- 카드번호·인증번호
- 비밀번호·보안매체 정보
- 불필요한 연락처·주소
- 민원 목적과 무관한 다른 상품 정보

## 내 금융정보 표시 규칙

- `내 금융정보 연결됨`과 조회 동의 상태만 요약 표시한다.
- 고객 ID `CUST-001`은 화면에 표시하지 않는다.
- 민원 판단에 필요한 상품·계좌만 연결한다.
- 거래내역 전체가 아니라 필요한 거래만 리포트에 사용한다.
- 조회 동의가 없으면 금융정보를 사용하지 않는다.

## 근거 표시 규칙

RAG 후보는 별도 노드로 만들지 않고 리포트의 `판단 근거`에 묶는다. 사용자가 클릭하면 다음만 보여준다.

```text
문서명
출처
페이지·조항
시행일
짧은 인용문
근거가 판단에 사용된 이유
```

검색 점수와 검색 방식은 사용자에게 보여주지 않는다.

## 제출 범위

원문 전체를 자동 제출하지 않는다. 금융회사나 기관에 전달할 자료를 안내할 때는 필요한 페이지·항목만 제안하고, 실제 제출은 사용자의 명시적 확인 이후 별도 절차로 처리한다.
