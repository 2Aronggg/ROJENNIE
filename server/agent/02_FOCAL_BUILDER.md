# Focal Builder Rules

## 목적

민원에서 판단의 중심이 되는 계약·거래·안내문·답변서·증빙과 조치 대상을 구조화한다.

## focal 후보

- 계약서·약관
- 거래내역·계산서
- 우대금리·수수료 변경 안내
- 보험금·환급금 지급 거절 통지
- 금융회사 민원 답변
- 문자·이메일·통화 기록
- 신분 도용 또는 인증 기록

## 사실 기록 규칙

각 사실에 다음을 기록한다.

```json
{
  "field": "interest_rate",
  "value": "5.1%",
  "source_ref": "notice_001",
  "event_date": "2026-06-01",
  "recorded_date": "2026-06-03",
  "confidence": 0.9,
  "conflicts_with": []
}
```

`recorded_date`가 늦다고 `event_date`도 최신이라고 판단하지 않는다.

## target 규칙

target은 다음을 구분한다.

- 사실관계의 상대방: 금융회사·판매자·대리점
- 요청을 전달할 대상: 금융회사 민원창구·분쟁조정기관 등

대상이 모호하면 임의로 기관을 확정하지 않고 `ask`로 보낸다.

## 필수 누락 정보

민원 유형에 따라 계약일, 사건일, 금액, 상품명, 금융회사 답변, 계약서, 안내문 수신 여부를 확인한다. 누락 정보는 검색 전에 명시한다.
