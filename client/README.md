# Client

금융소비자 보호 에이전트의 사용자 화면 영역입니다.

## MVP 화면

1. 복합 문의 입력 및 파일 첨부
2. 민원별 분해 결과 카드
3. 사건 그래프 또는 처리 단계 상태
4. 규정·약관 근거 상세 패널
5. 누락 정보·제출 서류 체크리스트
6. `proceed / amend / ask / hold` 상태 표시
7. Human Review 대기 상태

## API 계약

- `POST /api/v1/cases/analyze`
- `GET /api/v1/cases/{case_id}`
- `POST /api/v1/cases/{case_id}/review`

화면은 모델의 자유 형식 텍스트를 직접 파싱하지 않고, server가 반환하는 구조화된 case schema를 사용합니다.

## 원칙

- 민원별 결과를 한 카드에 섞지 않는다.
- 근거 문서의 페이지·조항을 클릭해서 볼 수 있게 한다.
- 개인정보 원문은 기본적으로 표시하지 않는다.
- `hold`를 오류처럼 보이지 않게 하고 검토 사유와 다음 단계를 표시한다.

현재는 UI 코드 없이 화면·API 계약만 정의되어 있습니다.

## B Client 구현 방향

### 디자인 톤

KB의 브랜드 컬러인 골드·옐로우를 중심으로 한 프리미엄 금융·AI 서비스 스타일로 구현합니다. 전체 배경은 화이트와 아이보리 계열로 밝고 깔끔하게 구성하고, 주요 오브젝트는 골드 메탈과 투명 아크릴 소재의 3D 그래픽을 활용합니다.

로고를 핵심 비주얼로 배치하고, 주변에는 금융·보안·법률·데이터 분석을 상징하는 아이콘과 차트 패널을 배치합니다. 카드와 패널은 둥근 모서리, 얇은 골드 테두리, 부드러운 그림자와 반투명 글래스모피즘 효과를 적용합니다.

전체적으로 복잡하지 않으면서도 신뢰감, 전문성, 기술력을 느낄 수 있는 미래지향적 금융 서비스 분위기로 구현합니다.

### 컬러 팔레트

- 메인 컬러: KB 옐로우, 골드
- 보조 컬러: 크림, 아이보리, 화이트, 샴페인 골드, 다크 차콜
- 강조 요소: 선명한 골드와 옐로우
- 본문과 제목: 블랙 또는 다크 그레이

### 비주얼 요소

- 중앙에는 KB 로고 또는 핵심 서비스 오브젝트를 배치합니다.
- 주변에는 금융기관, 문서, 보안 방패, 체크, 법률 저울, 성장 차트, 데이터 패널 등을 유리 구체나 투명 카드 형태로 배치합니다.
- 로봇 캐릭터나 귀여운 마스코트는 사용하지 않습니다.
- 브랜드 로고와 금융 오브젝트 중심으로 구성합니다.

### UI 스타일

- 둥근 카드형 레이아웃, 반투명 패널, 얇은 골드 라인, 소프트 섀도, 넉넉한 여백을 사용합니다.
- 데이터 영역은 도넛 차트, 막대그래프, 라인차트, 체크리스트 등으로 시각화합니다.
- 정보 위계가 명확하게 보이도록 구성합니다.
- 애니메이션은 과하지 않게 페이드인, 플로팅, 미세한 글로우, 오브젝트 부유 효과 정도로 적용합니다.
