# Content Scope Rules

## 목적

민원 처리에 필요한 정보와 외부에 표시·제출해도 되는 정보를 분리한다.

## 기본 범위

```text
allowed_fields   목적에 필요한 정보
excluded_fields  목적과 무관하거나 민감한 정보
masked_fields    일부만 표시할 정보
requires_user_confirmation  외부 제출 전 확인이 필요한 항목
```

## 기본 마스킹 대상

- 주민등록번호
- 전체 계좌번호
- 카드번호와 인증번호
- 비밀번호·보안매체 정보
- 민원과 무관한 제3자 개인정보
- 민원과 무관한 의료·소득 정보

## 제출 범위

원본 전체를 기본값으로 사용하지 않는다. 쟁점과 기간에 필요한 페이지·항목만 선택한다.

외부 기관 또는 금융회사로 전달하려면 사용자의 명시적 확인이 필요하다.
